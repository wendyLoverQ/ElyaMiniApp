# 透明锦鲤池 / Transparent Koi Pond

基于主人指定的本地 Wallpaper Engine 资源 3807744786 制作。保留原版锦鲤绘制、鱼群、荷花、乌龟、蝴蝶蜻蜓、图鉴、成长、自绘花纹、天气与合成环境音；移除池底、水色、石头、整屏纸纹、光斑、暗角、树影和冰层背景。

导入整个文件夹，入口为 manifest.json。透明空白区域不拦截桌面点击。荷花图标用于宿主拖动，鱼和场景物体保留内部交互，喂食按钮向池中撒食。默认隐藏时钟、关闭声音、使用手动晴天。

每个实例独立保存设置、我的锦鲤、鱼群档案和图鉴，使用 Elya Runtime 的 pond-state 一致快照；恢复先于所有场景模块初始化。高频修改合并保存，失败明确显示，不读取或转换原壁纸的浏览器存档。临时位置、动画、面板页签和鱼食不持久化。天气仅经 Elya 受控联网，需允许 Open-Meteo 两个 origin。无远程字体、外部依赖或壁纸软件接口。
